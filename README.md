# Печеньки для Lampa

Пункт «Печеньки» в боковом меню и настройках Lampa для управления нашими расширениями.

## Установка

После включения GitHub Pages файл плагина будет доступен по адресу:

https://str1kzz.github.io/lampa-plugins/pechenki.js

В Lampa открыть **Настройки → Расширения → Добавить плагин**, вставить адрес и полностью перезапустить приложение.

## Версия 0.1.0

- Пункт «Печеньки» в боковом меню.
- Одноимённый раздел в стандартных настройках с управлением пультом.
- Общий переключатель «Включить наши функции» с сохранением выбора.
- Основа для отдельных переключателей будущих функций.

Готовых дополнительных функций пока нет. Они будут появляться в следующих обновлениях. Общий выключатель оставляет доступ к меню настроек.

## Совместимость

Разработано для Lampa с SettingsApi, целевая платформа — Android TV. Проверено автоматическими тестами API; проверка на физической приставке пока не выполнена.
