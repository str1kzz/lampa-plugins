# Печеньки для Lampa

Наши настройки и небольшие расширения для Lampa на Android TV.

## Установка и обновление

Адрес плагина: **https://str1kzz.github.io/lampa-plugins/pechenki.js**

В Lampa открыть **Настройки → Расширения → Добавить плагин**, вставить адрес и полностью перезапустить приложение. Если плагин уже установлен, повторно добавлять его не нужно — достаточно полностью перезапустить Lampa.

Открыть **Печеньки** в боковом меню или общих настройках. Внизу раздела указана версия.

## Версия 0.1.1

- **Мое любимое** — визуальный розыгрыш: на главной постеры, названия и год становятся «Ранетками» (2008). Выключение возвращает обычный вид. По умолчанию выключено.
- Постер показывает актрис и крупную надпись «Ранетки»; изображение встроено в плагин.
- Данные настоящих фильмов и переходы в карточки сохраняются. Поиск, закладки и страницы фильмов остаются обычными.
- Общий выключатель **Включить наши функции** отключает изменения, сохраняя выбор отдельных функций.
- Поддерживается подгрузка новых карточек на главной.

Версия 0.1.0 проверена пользователем на приставке. Версия 0.1.1 проверена автоматическими тестами и на тестовой странице браузера; подтверждение на приставке ещё ожидается.

Постер: [Кинопоиск, рекламный постер «Ранеток»](https://www.kinopoisk.ru/picture/832243/).
