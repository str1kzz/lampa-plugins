# Печеньки для Lampa

Наши настройки и небольшие расширения для Lampa на Android TV.

## Установка и обновление

Адрес плагина: **https://str1kzz.github.io/lampa-plugins/pechenki.js**

В Lampa открыть **Настройки → Расширения → Добавить плагин**, вставить адрес и полностью перезапустить приложение. Если плагин уже установлен, повторно добавлять его не нужно — достаточно полностью перезапустить Lampa.

Открыть **Печеньки** в боковом меню или общих настройках. Внизу раздела указана версия.

## Версия 0.3.0

- **Аниме mvp** — пробный поиск аниме и дунхуа по разным названиям и быстрый переход к номеру серии.

## Аниме mvp

1. Откройте **Печеньки → Аниме mvp** и включите функцию. В боковом меню появится **Аниме mvp**.
2. Выберите **Найти по названию** и введите, например, `ван пис` или `One Piece`. Откройте карточку «Ван-Пис».
3. Выберите **К номеру серии** и введите `317`. Нужный блок откроется, серия будет выделена. Для перелистывания используйте **Предыдущие** и **Следующие**. «Назад» возвращает к результатам.

В MVP три демонстрационных тайтла и тестовые списки серий. Воспроизведение пока не подключено.

## Версия 0.2.2

- **Мое любимое** дополнено собственным рядом на главной с одной особенной карточкой и встроенным постером. Выключение полностью убирает ряд.
- **Киносвидание**: теперь можно выбрать несколько жанров и минимальный рейтинг TMDB (например, не ниже 7).

## Киносвидание

- Включите **Печеньки → Киносвидание**, затем откройте **Киносвидание** в боковом меню.
- Отметьте несколько жанров и нажмите **Готово**. Подойдут фильмы хотя бы одного из выбранных жанров. **Любой жанр** сбрасывает ограничения.
- Выберите длительность и минимальный **рейтинг TMDB**: любой, не ниже 5 / 6 / 6,5 / 7 / 7,5 / 8 / 8,5 / 9. Получите подборку до 12 фильмов. Если по строгим условиям фильмов меньше, они не расширяются автоматически.
- Оцените фильмы по очереди, передавая пульт: **Хочу / Можно / Нет**. Каждому доступно одно **Очень хочу!**.
- Второй зритель увидит те же фильмы в другом порядке. Оценки первого скрыты до финала. Чтобы сохранить сюрприз на общем экране, можно отвернуться на время чужого раунда.
- В финале — совпадения: взаимное «Хочу» выше компромиссов, любой ответ «Нет» исключает фильм. Можно выбрать фильм из списка или случайный среди совпадений.
- «Назад» во время раунда позволяет продолжить или закончить игру.
- **Мое любимое** — для особого настроения. Все изменения можно отключить.
- Общий выключатель **Включить наши функции** отключает изменения, сохраняя выбор отдельных функций.

Функции по умолчанию выключены. Голоса остаются в памяти текущей игры и не меняют закладки или историю. Каталог и постеры «Киносвидания» требуют доступа к TMDB через настройки Lampa. Постеры «Мое любимое» встроены в плагин. Наличие источника воспроизведения зависит от вашей настройки Lampa.

Работу предыдущих «Мое любимое» и «Киносвидания» пользователь подтвердил. Версия 0.2.2 проверена 39 автоматическими тестами и в официальной веб-сборке Lampa с тестовым каталогом; новые фильтры на приставке ещё не подтверждены.

Постер режима «Мое любимое»: [Кинопоиск](https://www.kinopoisk.ru/picture/832243/), встроен в плагин.
